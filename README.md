# KLEYN Workspaces

Personal workspace app: Spaces, Inbox, Capture, Queue, Voice notes.

Data stays in your browser (localStorage). This is not the official Grok app.

## Live site

https://klaysonklein.github.io/kleyn-workspaces/

If that 404s: repo Settings → Pages → Deploy from branch `main` / root.

## Install on iPhone

Open the live site in Safari → Share → Add to Home Screen.
